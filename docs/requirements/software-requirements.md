# 소프트웨어 요구사항 명세 (SRS) — 전자식 차일드락 제어 SW

- 문서 ID: SRS-ECL-001, 버전 0.1 (이터레이션 1, OEM 게이트 G1 대상, 베이스라인 BL-SWR-1.0 후보)
- 입력 문서: `OEM/OEM-SWR-001_OEM SW 요구사항 사양서.docx` (Rev 1.0, 이하 "OEM 사양서")
- 작성 정보: claude-sonnet-5-5, 2026-11-27, 요청자 DongJoonHan. 사용자 리뷰: 미완료.
- 기능 안전 요구사항(ASIL B)은 `docs/safety/safety-requirements.md`(`REQ-S-`)에서 관리하고, 이 문서에는 참조만 둔다.
- 추적성은 `docs/traceability/trace-matrix.md`에 둔다.

## 0. 용어

| 용어 | 정의 |
|---|---|
| 평가주기 | SW가 입력을 읽어 출력을 한 번 결정하는 반복 단위 (REQ-F-013) |
| 확정 출력 | 직전 평가주기에서 결정되어 공개된 좌/우 출력 |
| 필수 입력 | OEM-IF-001(속도·기어·타임스탬프), IF-002, IF-003, IF-007, IF-008, IF-009의 모든 항목 |
| 정지 | 유효한 vehicle_speed_kph 가 3.0 km/h 미만인 상태 (가정 A-06) |
| 출력 | 좌/우 각각 LOCK 또는 RELEASE (OEM-IF-005) |
| 상태 | ACTIVE, DEGRADED, FAULT, OFF 중 하나 (REQ-F-014) |
