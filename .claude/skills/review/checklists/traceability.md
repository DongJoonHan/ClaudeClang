# 추적성 리뷰 체크리스트 (전 단계 공통)

판정: OK / NG / N/A(사유) / 미확인

| ID | 점검 항목 | 판정 기준 |
|---|---|---|
| TR-01 | 모든 요구사항(`REQ-F/Q/L/C/S-`)이 상위 출처와 연결된다 | 고아 요구사항 없음 |
| TR-02 | 모든 요구사항이 아키텍처 요소에 연결된다 | 미할당 없음 |
| TR-03 | 모든 아키텍처 요소가 요구사항에 연결된다 | 근거 없는 요소 없음 |
| TR-04 | 아키텍처 요소가 상세 설계 모듈에 연결된다 | 미분해 요소 없음 |
| TR-05 | 상세 설계 모듈이 소스 코드와 단위 테스트에 연결된다 | 구현·시험 없는 모듈 없음 |
| TR-06 | 요구사항·아키텍처 인터페이스가 통합 테스트에 연결된다 | 시험 없는 항목 없음 |
| TR-07 | 모든 링크가 양방향으로 일치한다 (정/역방향 불일치 없음) | 불일치 0 |
| TR-08 | 링크 대상 ID가 실제로 존재한다 (끊어진 링크 없음) | 끊어진 링크 0 |
| TR-09 | 변경된 산출물의 영향받는 하위/상위 항목이 갱신·재확인되었다 | 최신 상태 |
| TR-10 | 시험 결과가 요구사항 단위로 추적된다 (통과/실패/미실시) | 요구사항별 상태 확인 가능 |
