# 단위 테스트 리뷰 체크리스트 (SWE.4)

판정: OK / NG / N/A(사유) / 미확인

| ID | 점검 항목 | 판정 기준 |
|---|---|---|
| UT-01 | 시험 케이스의 기대값이 상세 설계(사후조건/반환값)에서 도출되었다 | 코드 출력 베끼기 없음 |
| UT-02 | 모든 테스트 함수에 Doxygen 주석으로 목적, 입력값, 절차, 예상 출력값이 있다 | 항목 누락 없음 |
| UT-03 | 각 테스트에 추적 ID(`UT-`, 설계/요구사항)와 적용 기법이 기록되어 있다 | 누락 없음 |
| UT-04 | 동치 클래스 분할이 적용되었다 (유효/무효 클래스별 대표값) | 클래스 누락 없음 |
| UT-05 | 경계값 분석이 적용되었다 (직전/경계/직후, NULL, 0, 최대/최소) | 경계 누락 없음 |
| UT-06 | 다중 입력 조합에 PICT가 사용되었고 모델 파일이 보관되어 있다 | 모델·제약·생성 결과 존재 |
| UT-07 | 설계에 정의된 모든 오류 반환값에 대응하는 케이스가 있다 | 누락 없음 |
| UT-08 | 상태가 있는 모듈의 유효/무효 전이가 시험된다 | 해당 시 확인 |
| UT-09 | 목표 커버리지 종류와 수치가 계획과 일치하고 측정 결과가 100%이다 | 100% 또는 승인된 예외 |
| UT-10 | MC/DC 목표가 있는 경우 LLVM 도구로 측정했고 미충족 조건이 없다 | 해당 시 확인, 도구 버전 기록 |
| UT-11 | 커버리지만을 위한 의미 없는 케이스(검증 없는 호출, 항상 참인 단언 등)가 없다 | 모든 케이스가 검증 목적과 단언을 가짐 |
| UT-12 | 각 테스트에 의미 있는 단언이 있고 반환값·출력·상태를 확인한다 | 단언 없는 테스트 없음 |
| UT-13 | Stub/Mock이 외부 의존 경계에만 쓰였고 과도하지 않다 | 대상 내부 Mock 없음, 구현 세부 고정 없음 |
| UT-14 | 시험이 독립적이고 반복 가능하다 (순서·전역 상태 비의존) | 단독/무작위 순서 실행 통과 |
| UT-15 | 미커버 항목이 있으면 도달 불가 사유와 승인이 문서화되어 있다 | 사유·승인 존재 |
| UT-16 | 시험 보고서에 결과, 커버리지, 도구 버전이 기록되어 있다 | 기록 존재 |
| UT-17 | 설계/요구사항 ↔ 단위 테스트 추적이 완전하다 | 시험 없는 모듈/함수, 근거 없는 시험 없음 |
