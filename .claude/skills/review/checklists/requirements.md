# 요구사항 리뷰 체크리스트 (SWE.1)

판정: OK / NG / N/A(사유) / 미확인

| ID | 점검 항목 | 판정 기준 |
|---|---|---|
| RQ-01 | 모든 요구사항에 고유 ID가 있다 | ID 누락·중복 없음 |
| RQ-02 | 기능/품질/제한/제약사항으로 정확히 하나로 분류되어 있다 | 미분류·이중 분류 없음 |
| RQ-03 | 기능 안전 요구사항이 별도 문서(`docs/safety/`)에서 관리되고, 일반 문서에는 참조만 있다 | 일반 문서에 안전 요구 본문 없음 |
| RQ-04 | 품질 요구사항이 ISO 25010 특성/부특성에 매핑되어 있다 | 모든 `REQ-Q-`에 매핑 있음 |
| RQ-05 | 품질 요구사항에 정량 기준과 측정 조건이 있다 | 측정 가능한 수치/조건 존재 |
| RQ-06 | 미적용 품질 특성은 "해당 없음 + 사유"로 기록되어 있다 | 누락된 특성 없음 |
| RQ-07 | 각 요구사항이 한 문장 한 요구, "해야 한다" 형식이다 | 복합 요구 없음 |
| RQ-08 | 모호한 표현(적절히, 빠르게, 등)이 없다 | 모호어 없음 |
| RQ-09 | 각 요구사항이 검증 가능하고 검증 방법이 지정되어 있다 | 검증 방법 열 채워짐 |
| RQ-10 | 요구사항 사이에 충돌·중복이 없다 | 충돌·중복 목록 비어 있음 |
| RQ-11 | 요구사항이 구현 방법이 아닌 요구를 기술한다 (제약사항 제외) | how 서술 없음 |
| RQ-12 | 출처(이해관계자 요구/상위 문서)와 우선순위가 있다 | 모든 항목에 출처 있음 |
| RQ-13 | 상향 추적: 모든 요구사항이 상위 요구/출처와 연결된다 | 고아 요구사항 없음 |
| RQ-14 | 하향 추적: 모든 요구사항이 아키텍처에 할당된다 (또는 미할당 사유 명시) | 미할당 항목 없음 |
| RQ-15 | 안전 요구사항(`REQ-S-`)도 추적 매트릭스에 포함되어 있다 | 포함 확인 |
| RQ-16 | 미해결 질문·가정이 목록으로 남아 있다 | 임의 가정이 본문에 숨어 있지 않음 |
