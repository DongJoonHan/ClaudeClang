# 상세 설계 리뷰 체크리스트 (SWE.3)

판정: OK / NG / N/A(사유) / 미확인

| ID | 점검 항목 | 판정 기준 |
|---|---|---|
| DD-01 | 모든 컴포넌트가 모듈로 분해되어 있고 모듈에 ID, 책임, 소속 컴포넌트, 할당 요구사항이 있다 | 누락 없음 |
| DD-02 | 인터페이스 정의 대상 판정 기준이 명시되어 있고 일관되게 적용되었다 | 기준 문서화, 대상 모듈 모두 인터페이스 있음 |
| DD-03 | 인터페이스가 시그니처, 인자 범위/단위, 반환값, 사전/사후조건, 오류 처리를 포함한다 | 항목 누락 없음 |
| DD-04 | 인터페이스가 정의된 모듈은 인터페이스를 통해서만 접근된다 | 내부 함수/데이터 직접 접근 없음 |
| DD-05 | 아키텍처 인터페이스(`ARCH-I-`)가 모듈 인터페이스에 빠짐없이 반영된다 | 불일치 없음 |
| DD-06 | 모든 함수에 정상/오류 반환값이 정의되어 있다 (void 없음, 상태값 정의 있음) | 반환값 정의 누락 없음 |
| DD-07 | 함수별 처리 절차와 분기 조건, 오류 경로가 기술되어 있다 | 시험 가능한 수준으로 기술 |
| DD-08 | 모듈이 단일 책임을 가진다 (변경 이유가 하나) | 다목적 모듈 없음 |
| DD-09 | 함수가 한 가지 일을 하고 크기·인자 수가 적절하다 | 과대 함수/인자 과다 없음 |
| DD-10 | 이름이 의도를 드러내고 약어·중의어가 없다 | 위반 없음 |
| DD-11 | 매직 넘버·중복이 없다 (이름 있는 상수, DRY) | 위반 없음 |
| DD-12 | 부수효과와 전역 상태 사용이 드러나 있다 | 숨은 부수효과 없음 |
| DD-13 | 의존이 다른 모듈의 구현이 아닌 인터페이스를 향한다 | 구현 의존 없음 |
| DD-14 | 단위 시험 가능한 구조이다 (의존 분리 가능) | 시험 불가 구조 없음 |
| DD-15 | 아키텍처 ↔ 모듈 ↔ 요구사항 양방향 추적이 완전하다 | 고아 모듈, 미할당 요구사항 없음 |
